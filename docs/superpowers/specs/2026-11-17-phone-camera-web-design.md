# หน้าเว็บทดสอบด้วยกล้องมือถือ — design (สั้น)

## เป้าหมาย
ถ่ายรูปเมล็ดกาแฟด้วยกล้องมือถือ → ส่งไปคอม → คอมทำนาย → ส่งรูปที่วาดกรอบ + คลาสกลับมาแสดงบนมือถือ
ใช้ทดสอบโมเดลกับภาพจริงนอกชุด train

- Non-goal: ไม่ใช่ส่วนของงานส่ง · ไม่แก้ `infer.py`, `crop_beans.py`, `requirements.txt`
- Anti-goal: ต้องไม่ต้องตั้ง HTTPS / ไม่มีคำเตือนความปลอดภัยบนมือถือ

## Approaches
- **A. `<input capture>` เปิดแอปกล้องของมือถือ + Flask (เลือก)** — ใช้ผ่าน http ได้, ได้ภาพเต็มความละเอียด, ไม่มี live preview
- B. live preview ด้วย getUserMedia — ต้อง HTTPS + self-signed cert, ภาพความละเอียดต่ำกว่า
- C. Gradio — โค้ดน้อย แต่ dependency ใหญ่ ปรับ UI มือถือยาก

## Design
- ไฟล์ใหม่ `web_app.py` (Flask) · `requirements-web.txt` = `flask` (เพิ่มจาก requirements.txt เดิม)
- รัน `python web_app.py --weights weights/ [--port 8000]` → ฟังที่ `0.0.0.0` และพิมพ์ URL `http://<IP ในวง LAN>:8000` ให้เปิดบนมือถือ (ต้องอยู่ Wi-Fi เดียวกัน)
- โหลดโมเดลครั้งเดียวด้วย `infer.load_model()` · ใช้ lock กันเรียกโมเดลพร้อมกัน
- `GET /` หน้าเดียว ออกแบบสำหรับมือถือ: ปุ่มใหญ่ "ถ่ายรูป" (`accept="image/*" capture="environment"`) + ปุ่มเลือกจากคลัง · เลือกเสร็จส่งอัตโนมัติ, แสดงสถานะกำลังทำนาย
- `POST /predict` (multipart): อ่านภาพ + EXIF orientation (`crop_beans.load_image` รับ BytesIO) → `extract_beans(..., return_boxes=True)` → ทำนายรายเม็ด → เฉลี่ย prob = คลาสของภาพ (ตรรกะเดียวกับ `predict_image`) → วาดกรอบสีตามคลาส + ชื่อคลาสรายเม็ด → ย่อด้านยาว ~1280 px → ตอบ JSON: คลาสของภาพ, ความมั่นใจ, จำนวนเม็ดต่อคลาส, ภาพผล (JPEG base64)
- แยกเม็ดไม่ได้: ใช้กลางภาพแทนเหมือน `infer.py` และแสดงคำเตือนบนหน้า
- ไม่บันทึกภาพที่อัปโหลดลงดิสก์ · ไฟล์ผิดประเภท/อ่านไม่ได้ → ข้อความ error บนหน้า
